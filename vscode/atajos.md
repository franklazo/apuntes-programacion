# Atajos de Teclado

## Gestión de Archivos

- `Ctrl + N`            → Nuevo archivo
- `Ctrl + K` `Ctrl + O` → Abrir carpeta...
- `Ctrl + S`            → Guardar
- `Ctrl + Shift + S`    → Guardar como...
- `Ctrl + Shift + T`    → Reabrir archivo cerrado

## Cursor de Texto

- `Click`        → Ir a posición...
- `↑ / ↓`        → Ir a línea arriba/abajo
- `← / →`        → Ir a carácter izquierdo/derecho
- `Ctrl + ← / →` → Ir a palabra izquierda/derecha
- `Home / End`   → Ir a inicio/final de línea
- `Ctrl + Home`  → Ir a inicio de texto
- `Ctrl + End`   → Ir a final de texto

### Multicursor

- `Alt + Click`        → Insertar
- `Ctrl + Alt + ↑ / ↓` → Insertar cursor arriba/abajo
- `Ctrl + U`           → Deshacer última operación de cursor
- `Esc`                → Borrar cursores

### Selección

- `Drag`                      → Seleccionar
- `Click` `x2`                → Seleccionar palabra
- `Click` `x3`                → Seleccionar línea
- `Click` `x4`                → Seleccionar texto
- `Shift + Click`             → Expandir/contraer selección
- `Shift + ↑ / ↓`             → Expandir/contraer selección a línea arriba/abajo
- `Shift + ← / →`             → Expandir/contraer selección a carácter izquierdo/derecho
- `Ctrl + Shift + ← / →`      → Expandir/contraer selección a palabra izquierda/derecha
- `Shift + Home / End`        → Expandir/contraer selección a inicio/final de línea
- `Ctrl + Shift + Home / End` → Expandir/contraer selección a inicio/final de texto
- `Shift + Alt + ← / →`       → Expandir/contraer selección
- `Ctrl + A`                  → Seleccionar texto
- `Ctrl + L`                  → Seleccionar línea actual
- `Ctrl + D`                  → Seleccionar siguiente coincidencia de la selección actual
- `Ctrl + Shift + L`          → Seleccionar todas las coincidencias de la selección actual

## Edición

### Básica

- `Ctrl + Z`             → Deshacer
- `Ctrl + Y`             → Rehacer
- `Drag and drop`        → Mover selección
- `Ctrl + Drag and drop` → Copiar selección
- `Ctrl + C`             → Copiar selección o línea (selección vacía)
- `Ctrl + X`             → Cortar selección o línea (selección vacía)
- `Ctrl + V`             → Pegar selección o línea
- `Backspace` , `Del`    → Borrar selección
- `Ctrl + Shift + K`     → Borrar línea
- `Alt + ↑ / ↓`          → Mover línea arriba/abajo
- `Shift + Alt + ↑ / ↓`  → Copiar línea arriba/abajo

### De Código

- `Ctrl + Space` → Activar sugerencia (`Tab` para autocompletar)
- `Ctrl + Ç`     → Alternar comentario de línea
- `Alt + Z`      → Alternar ajuste de línea
- `Insert`       → Alternar sobrescritura
- `F2`           → Renombrar símbolo

### Personalizada

- `Shift + Alt + L` → Convertir a minúscula
- `Shift + Alt + U` → Convertir a mayúscula
- `Shift + Alt + T` → Convertir a capitalizado

## Interfaz

- `Ctrl + Ñ`                → Mostrar terminal integrada
- `Ctrl + B`                → Alternar visibilidad de barra lateral
- `Ctrl + Shift + P` , `F1` → Paleta de comandos
- `Ctrl + Shift + N`        → Nueva ventana
- `Ctrl + ,`                → Configuración
- `Ctrl + K` `Ctrl + S`     → Atajos de teclado
- `Ctrl + K` `Z`            → Modo zen (`Esc` `x2` para salir)

### Navegación

- `Ctrl + Tab`         → Navegar historial del grupo de edición
- `Ctrl + Shift + Tab` → Navegar historial del grupo de edición
- `Ctrl + ↑ / ↓`       → Desplazar vista una línea arriba/abajo
- `Ctrl + Click`       → Abrir enlace
- `Alt + ← / →`        → Ir atrás/adelante

### Buscar y Reemplazar

- `Ctrl + F` → Buscar
- `Ctrl + H` → Reemplazar
