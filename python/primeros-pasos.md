# Primeros pasos

## Acerca de Python

- Código abierto (*open source*)
- Alto nivel, multiplataforma, multiparadigma
- Interpretado, tipado dinámico y tipado fuerte
- Aplicaciones de escritorio, web (*frontend*) o servidor (*backend*)

## Instalación

- Descargar el instalador desde el sitio oficial de [Python](https://www.python.org/).
- Agregar el programa al **PATH** en el proceso de instalación.

### Mostrar versión

```powershell
python --version
```
