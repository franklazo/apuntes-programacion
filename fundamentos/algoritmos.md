# Algoritmos

- Un **algoritmo** es una secuencia finita y ordenada de pasos para resolver un problema o realizar una tarea.
- Un algoritmo puede expresarse mediante:
  - Lenguaje natural
  - Pseudocódigo.
  - Diagrama de flujo.
  - Lenguaje de programación.
- Un **programa informático** es la implementación de un algoritmo en un lenguaje de programación.

## Lógica de programación

- La **lógica de programación** es la capacidad de diseñar algoritmos para resolver problemas de forma correcta y eficiente.
- Un algoritmo recibe uno o más **datos de entrada**, realiza un **proceso** sobre ellos y produce uno o más **datos de salida**.

Un modelo básico para comprender el funcionamiento de un algoritmo es el modelo **Entrada-Proceso-Salida** (**IPO**):

- **Entrada**: datos que recibe un algoritmo para resolver un problema.
- **Proceso**: conjunto de operaciones que transforman los datos de entrada.
- **Salida**: resultado obtenido después de ejecutar el algoritmo.

```text
Problema: calcular el área de un círculo.

Entrada:  radio
Proceso:  área = π × radio²
Salida:   área del círculo
```

## Errores de programación

Son fallos en un programa que impiden su correcto funcionamiento o producen resultados incorrectos:

- **Error de sintaxis:** ocurre cuando el código no cumple las reglas del lenguaje de programación.
- **Error de ejecución**: ocurre durante la ejecución del programa e impide que este continúe o se comporte como se espera.
- **Error lógico**: ocurre cuando el programa se ejecuta correctamente, pero produce resultados incorrectos.

La **depuración** (*debugging*) es el proceso de localizar, analizar y corregir errores de un programa.
