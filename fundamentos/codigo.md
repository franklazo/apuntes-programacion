# Código fuente

El **código fuente** es el conjunto de instrucciones escritas en un lenguaje de programación que le indican a una computadora qué debe hacer.

## Herramientas y recursos

- **Editor de código**: aplicación que permite escribir y editar código fuente.
- **Entorno de Desarrollo Integrado** (**IDE**): aplicación que integra un editor de código y herramientas para desarrollar, ejecutar, depurar y gestionar programas.
- **Terminal** o **consola**: interfaz de texto que permite ejecutar comandos y programas.
- Una **biblioteca** proporciona funciones que el programador utiliza cuando las necesita.
- Un **framework** proporciona una estructura sobre la que se desarrolla una aplicación.
- Una **API** es una interfaz que permite que distintos programas puedan comunicarse entre sí.

## Sintaxis

**Conjunto de reglas** que determinan cómo se escriben las instrucciones y se estructura el código de un lenguaje de programación.

### Variables

- La información que utiliza un programa se almacena temporalmente en la **memoria RAM**.
- Una **variable** es un nombre que identifica una posición de memoria donde se almacena un dato.
- Un **identificador** es el nombre que recibe una variable, función u otro elemento del programa.
- La **asignación** es la operación mediante la cual se almacena un valor en una variable.
- El **valor** de una variable es el dato almacenado en ella.

### Condicionales

- Una **condición** es una expresión cuyo resultado es verdadero o falso.
- Un **bloque de código** es un conjunto de instrucciones que se ejecutan como una unidad.
- Una **condicional** es una estructura de control que permite hacer decisiones en el flujo del programa.

### Bucles

- Un **bucle** es una estructura de control que permite repetir un bloque de código.
- Una **iteración** es cada repetición del bloque de código.
- La **condición de parada** determina cuándo finaliza el bucle.
- El **contador** es una variable utilizada para llevar la cuenta de las iteraciones (si corresponde).

### Funciones

- Una **función** es un bloque de código reutilizable que realiza una tarea específica.
- Un **parámetro** es una variable definida por una función para recibir datos.
- Un **argumento** es el valor que se pasa a un parámetro al llamar a la función.
- El **valor de retorno** es el resultado que una función devuelve.
