# Lenguajes de programación

Características principales de los lenguajes de programación

## Compilación e interpretación

Como la computadora no puede ejecutar directamente el código fuente, este debe traducirse a código máquina mediante un proceso de **compilación** o **interpretación**, según el lenguaje utilizado.

### Compilación

- Un proceso de **compilación** traduce un programa completo antes de su ejecución.
- Un **compilador** es un programa que realiza este proceso.
- Un **lenguaje compilado** requiere un proceso de **compilación** antes de su ejecución.

### Interpretación

- Un proceso de **interpretación** traduce y ejecuta un programa instrucción por instrucción durante su ejecución.
- Un **intérprete** es un programa que realiza este proceso.
- Un **lenguaje interpretado** ejecuta sus programas mediante un proceso de **interpretación**.

## Paradigmas de programación

Un **paradigma de programación** es una forma o estilo de diseñar y estructurar programas para resolver problemas:

- **Programación imperativa**: describe paso a paso las instrucciones que debe ejecutar la computadora.
- **Programación procedimental**: organiza el programa en procedimientos o funciones reutilizables.
- **Programación orientada a objetos**: organiza el programa mediante objetos que combinan datos y comportamiento.
- **Programación funcional**: construye programas mediante funciones puras y evita modificar el estado de los datos.
- **Programación lógica**: resuelve problemas mediante hechos y reglas lógicas, dejando que el sistema deduzca las soluciones.
- **Programación orientada a eventos**: el flujo del programa depende de eventos, como clics del usuario, pulsaciones de teclas o mensajes del sistema.
- **Programación concurrente**: permite ejecutar varias tareas de forma simultánea o coordinada.

## Características generales

- **Multiparadigma**: permite desarrollar programas utilizando más de un paradigma de programación.
- **Multiplataforma**: puede ejecutarse en distintos sistemas operativos y arquitecturas de hardware con pocos o ningún cambio.
- **Código abierto**: modelo de desarrollo de software en el que el código fuente es público, puede ser estudiado, modificado y distribuido por cualquier persona según los términos de su licencia.

## Tipado de un lenguaje

Según **cuándo** se conoce el tipo de dato:

- **Tipado dinámico**: el tipo de una variable se determina durante la ejecución del programa.
- **Tipado estático**: el tipo de una variable se determina antes de la ejecución del programa.

Según **cómo** se tratan las conversiones de tipos:

- **Tipado fuerte**: restringe las conversiones automáticas entre tipos incompatibles.
- **Tipado débil**: permite más conversiones automáticas entre distintos tipos de datos.

## Nivel de abstracción

- Se denomina **lenguaje de bajo nivel** al lenguaje cuyas instrucciones están muy próximas al funcionamiento del hardware, permitiendo un control directo de sus recursos. Un ejemplo es el **lenguaje ensamblador**.
- Se denomina **lenguaje de alto nivel** al lenguaje cuyas instrucciones se asemejan más al lenguaje humano y abstraen gran parte del funcionamiento del hardware. Un ejemplo es **Python**.
- Se suele denominar **lenguaje de medio nivel** al lenguaje que combina características de los lenguajes de alto y bajo nivel, permitiendo un mayor control sobre el hardware sin dejar de ofrecer una sintaxis relativamente sencilla. El ejemplo más representativo es **C**.
