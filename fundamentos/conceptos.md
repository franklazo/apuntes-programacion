# Conceptos básicos

## Computadora

- Una **computadora** u ordenador es una máquina electrónica capaz de **recibir**, **almacenar**, **procesar** y **transmitir información** siguiendo una serie de instrucciones para producir determinados resultados.
- La parte física de una computadora se denomina **hardware**.
- La parte intangible de una computadora se denomina **software**.

## Programa informático

- Un **programa informático** es un conjunto de instrucciones que una computadora puede ejecutar.
- La **programación** es el proceso de diseñar, escribir, probar, depurar, mantener y mejorar programas informáticos.
- Un **programador** es la persona que diseña, desarrolla y mantiene programas informáticos mediante la programación.

## Lenguaje de programación

- Así como las personas utilizan un **lenguaje** para comunicarse entre sí, para indicar a una computadora qué debe hacer se utiliza un **lenguaje de programación**.
- Un **lenguaje de programación** es un lenguaje formal que permite escribir programas mediante un conjunto de reglas y símbolos definidos.
- Un **programa** escrito en un lenguaje de programación se denomina **código fuente**.
- La computadora sólo puede ejecutar **código máquina**, formado por instrucciones representadas mediante los dígitos **0** y **1** (sistema binario).
- El código máquina suele representarse en **sistema hexadecimal** para facilitar su lectura y escritura por parte de las personas.
