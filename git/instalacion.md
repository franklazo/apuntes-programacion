# Instalación

Descargar el instalador desde el sitio oficial de [Git][git]

## Versión

```powershell
git --version
```

## Configuración

```powershell
# Agregar datos del usuario en modo global
git config --global user.name "Nombre de usuario"
git config --global user.email "usuario@example.com"
```

```powershell
# Comprobar configuración
git config --list
```
